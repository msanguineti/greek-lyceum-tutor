# Περιεχόμενο και όρια

Η συλλογή **0.8.1** περιλαμβάνει τέσσερα αυτοτελή πακέτα για τις Πανελλαδικές 2027:

| Πεδίο | Έκδοση | Μαθήματα πέρα από τη Γλώσσα και Λογοτεχνία |
| --- | --- | --- |
| 1ο | 0.1.0 | Αρχαία Ελληνικά, Ιστορία, Λατινικά |
| 2ο | 0.7.6 | Μαθηματικά, Φυσική, Χημεία |
| 3ο | 0.1.1 | Φυσική, Χημεία, Βιολογία |
| 4ο | 0.1.0 | Μαθηματικά, Οικονομία, Πληροφορική |

Κάθε πακέτο έχει έξι Skills, ιδιαίτερους χάρτες ύλης, προέλευση πηγών και ρητές εξαιρέσεις. Οι κοινές οδηγίες διατηρούν ελληνικές εκπαιδευτικές ετικέτες και προσαρμόζονται σε αιτήματα για συντομία, υποδείξεις, πλήρεις λύσεις ή διόρθωση χωρίς βαθμό.

Τα έξι επίσημα διοικητικά πρωτότυπα περιλαμβάνονται αμετάβλητα. Βιβλία, παλαιά θέματα και πλήρεις οδηγοί ΙΕΠ διατίθενται μόνο με σύνδεσμο. Οι επιλεγμένες εξεταστικές καταχωρίσεις περιέχουν εντοπιστές, μονάδες και συμβατότητα, χωρίς αποθηκευμένες εκφωνήσεις, κλειδιά ή λύσεις. Η παρουσία σε παλαιό φυλλάδιο δεν εγκρίνει ολόκληρο το θέμα για το 2027.

Οι χάρτες ελέγχθηκαν έναντι των επίσημων πηγών στις ημερομηνίες που δηλώνουν. Ο [αρχικός έλεγχος της 18ης Οκτωβρίου 2026](../skills/lyceum-study/references/shared/curriculum-audit-2026-10-18.md) αφορά τα τέσσερα μαθήματα του 2ου πεδίου· τα νέα μαθήματα έχουν δική τους προέλευση και ελέγχους. Δεν υπάρχει αυτόματη ενημέρωση για μεταγενέστερες αλλαγές.

Έγιναν πραγματικοί έλεγχοι ChatGPT web και στα τέσσερα πεδία, με αντιπροσωπευτικές περιπτώσεις διδασκαλίας, πηγών, εξαιρέσεων, ελληνικών αναπαραστάσεων και εκπαιδευτικής διόρθωσης. Αυτό δεν αποτελεί εξαντλητικό έλεγχο κάθε πιθανής ερώτησης ή πιστοποίηση από εκπαιδευτικό. Και τα τέσσερα πακέτα εισήχθησαν και εγκαταστάθηκαν σε προσωπικό Free λογαριασμό μέσω ChatGPT web, με έξι δεξιότητες το καθένα. Ο έλεγχος διανομής δεν πιστοποιεί κάθε διδακτική λειτουργία ή δυνατότητα εργαλείου του Free προγράμματος. Η συλλογή διανέμεται ως τέσσερα ZIP με ένα αυτοτελές plugin το καθένα, έτοιμα για απευθείας μεταφόρτωση χωρίς αποσυμπίεση. Οι διδακτικές οδηγίες και οι εκδόσεις των tutors παραμένουν ίδιες. Ο κατάλογος GitHub χρειάζεται ακόμη ενεργοποίηση και πραγματικό έλεγχο εγκατάστασης. Δεν έχει εντοπιστεί επιλογή εγκατάστασης στην εφαρμογή κινητού.

Μεγάλα PDF ή κρίσιμα σχήματα μπορεί να μην είναι αναγνώσιμα σε κάθε περιβάλλον. Για τις πρωτεΐνες Βιολογίας Α΄ υπάρχει ελεγμένη επίσημη HTML εναλλακτική. Η ανάγνωση HTML δεν πιστοποιεί οπτικό έλεγχο του PDF. Όταν λείπει κρίσιμο υλικό, ο tutor πρέπει να το δηλώνει και να ζητά μόνο το αναγκαίο απόσπασμα ή να προτείνει σαφώς πρωτότυπη εξάσκηση.

Η ήδη εγκατεστημένη μοιρασμένη έκδοση του 2ου πεδίου δεν ενημερώνεται με τη λήψη ή την έκδοση αυτών των αρχείων. Δεν υπάρχει απαίτηση αποκλειστικής χρήσης των tutors σε υπολογιστή.

Η 0.7.6 του 2ου πεδίου ενημερώνει τις σημειώσεις δικαιωμάτων για χρήση σε όλα τα πακέτα και τα στοιχεία έκδοσης· οι διδακτικές οδηγίες του παραμένουν ίδιες με την 0.7.5. Η εγκατεστημένη μοιρασμένη έκδοση παραμένει 0.7.5.
