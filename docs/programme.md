# Πεδία και εκπαιδευτική κάλυψη

Οι βοηθοί απευθύνονται σε μαθητές της Γ΄ ΓΕΛ που προετοιμάζονται για τις Πανελλαδικές 2027. Υπάρχει χωριστός tutor για κάθε Επιστημονικό Πεδίο, ώστε να χρησιμοποιείς το υλικό που χρειάζεσαι.

| Πεδίο | Μαθήματα |
| --- | --- |
| 1ο | Νεοελληνική Γλώσσα και Λογοτεχνία, Αρχαία Ελληνικά, Ιστορία, Λατινικά |
| 2ο | Νεοελληνική Γλώσσα και Λογοτεχνία, Μαθηματικά, Φυσική, Χημεία |
| 3ο | Νεοελληνική Γλώσσα και Λογοτεχνία, Φυσική, Χημεία, Βιολογία |
| 4ο | Νεοελληνική Γλώσσα και Λογοτεχνία, Μαθηματικά, Οικονομία, Πληροφορική |

Κάθε tutor περιλαμβάνει επίσης οργάνωση μελέτης και εξάσκηση εξετάσεων. Μπορείς να ζητήσεις βοήθεια σε συγκεκριμένο θέμα, επανάληψη, πρωτότυπες ασκήσεις ή προσομοίωση. Οι υποδείξεις προηγούνται συνήθως της πλήρους λύσης· αν χρειάζεσαι διαφορετικό τρόπο βοήθειας, γράψε το στο μήνυμά σου.

Η κάλυψη αφορά την επίσημη εξεταστέα ύλη 2027 και τις ρητές εξαιρέσεις της. Δεν περιλαμβάνει ΕΠΑΛ, άλλες τάξεις, ειδικά μαθήματα εισαγωγής, ξένες γλώσσες, μουσική, σχέδιο ή αθλητικές δοκιμασίες.

Οι tutors παραμένουν πειραματικά βοηθήματα. Δες το [περιεχόμενο και τα όρια](status.md) πριν βασιστείς σε μια απάντηση. Για να ξεκινήσεις, [διάλεξε το πεδίο σου και κατέβασε το ZIP](../README.md#διάλεξε-τον-tutor-σου).
